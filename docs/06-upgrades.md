# Section 10: Upgrade System

All upgrades are purchased from the **Upgrade Menu** (wrench icon in the top bar).
Front and backroom upgrades are in separate tabs. Each upgrade has 5 levels.
Prices scale using the formula: `base_price × 2.5^(level-1)` (rounded), giving a satisfying
but not punishing progression curve.

Format per upgrade:
**L1–L5:** Description | **Price** | **Effect** | **Visual** | **Funny name**
