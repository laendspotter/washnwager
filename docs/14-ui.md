# Section 20: UI Design (Mobile)

All UI text is in **English**. Designed for mobile (portrait mode primary, landscape
optional). Touch-first interaction model. No text smaller than 14px effective size at
standard mobile DPI. All interactive elements minimum 44×44 px tap target.

---

## Top Bar

The top bar is always visible. Fixed to the top of the screen.

```
┌──────────────────────────────────────────────────┐
│  💰 $4,820    🌡️ ████░░░ 42    ⭐ ████████ 78   │
│  [TASK ▼]                              [MENU ≡]  │
└──────────────────────────────────────────────────┘
```

### Elements:

**💰 Money Counter**
- Displays current coins balance.
- Ticking animation when income flows in (numbers tick up smoothly, not jump).
- Font: Bold, warm cream-white text on a dark gold background pill.
- Large enough to read at a glance.

**🌡️ Heat Meter**
- Label: "HEAT" in small caps
- Bar fills from left to right, color-transitions: green → yellow → orange → red.
- At 75+: bar pulses slightly (glow effect).
- At 100: bar flashes + short audio sting.
- Tapping the heat bar opens the **Heat Detail Popup** (shows what's actively raising/lowering heat).

**⭐ Reputation Bar (Laundromat)**
- Label: "RATING" in small caps
- Star-gold color fill.
- Tapping opens the **Reputation Detail Popup** (shows all 3 reputation sub-bars):
  - ⭐ Laundromat Reputation
  - 🃏 Backroom Reputation (hidden in early game; reveals at Chapter 4)
  - 💬 Town Suspicion

**[TASK ▼] Task Button**
- Opens the **Task Queue panel** (see below).
- Shows a number badge if there are active urgent tasks (red badge, white number).
- Color: Always slightly warm-amber to draw the eye.

**[MENU ≡] Hamburger Menu**
- Opens the full menu overlay: Upgrades, Staff, Story, Quests, Achievements, Settings.

## Task Queue Panel

Opens from the [TASK ▼] button. Slides up from the bottom of the screen.

```
┌────────────────────────────────────┐
│  TASKS (3)              [Close ✕]  │
├────────────────────────────────────┤
│  🔴 Washer 2 broken       [Fix]    │
│  🟡 Vending empty         [Restock]│
│  🟢 Coins ready           [Collect]│
└────────────────────────────────────┘
```

- Tasks sorted by priority: 🔴 critical, 🟡 moderate, 🟢 passive.
- Tapping [Fix] dispatches the appropriate staff member OR sends Retta if staff unavailable.
- Tapping [Restock] deploys Hector.
- Tapping [Collect] sends Retta (or auto-collects if the coin auto-collector is installed).
- Swipe to dismiss minor tasks (green tier only).

## Upgrade Menu

Opens from [MENU ≡] → Upgrades.
Two tabs: **FRONT** and **BACK ROOM** (Back Room tab locked until Chapter 4).

```
┌──────────────────────────────────────────┐
│  UPGRADES        [FRONT] | [BACK ROOM]   │
├──────────────────────────────────────────┤
│  🫧 Washers         ████░  L4  [$3,125]  │
│  🌀 Dryers          ███░░  L3  [$3,750]  │
│  🧴 Detergent Shelf ██░░░  L2  [$500]    │
│  🥤 Vending         █░░░░  L1  [$400]    │
│  ...                                     │
│                         [Upgrade All ▼]  │
└──────────────────────────────────────────┘
```

- Each row: icon + name + progress dots (showing current level) + price button.
- Tapping a row expands it: shows L1–L5 descriptions, current level highlighted.
- Price button: gold-filled if affordable, gray if not.
- "Upgrade All" shortcut: one-tap upgrades all affordable Level 1 items (useful early game).
- Max-level items show a ✨ star and no price button.

## Event Popup

Appears mid-game when a dialogue event triggers. Slides in from the right (mobile-friendly).
The game does NOT pause entirely — the laundromat continues running at 50% speed during an event.

```
┌─────────────────────────────────────────┐
│  [NPC PORTRAIT]  CONNIE DUPREE          │
│  ─────────────────────────────────────  │
│  "Loretta, I don't want to be one of    │
│  those people who asks, but I'm going   │
│  to ask..."                             │
│                                         │
│  WHAT DO YOU DO NOW?                    │
│  ─────────────────────────────────────  │
│  [A] "That's staff entrance."           │
│  [B] "VIP laundry service, come see!"   │
│  [C] "Oh, Connie, did you hear about    │
│       Wade's week?"                     │
└─────────────────────────────────────────┘
```

- NPC portrait: small 32×32 animated sprite in a speech bubble frame.
- NPC dialogue: 2–3 lines, never more.
- "WHAT DO YOU DO NOW?" — all caps, warm amber color, underlined.
- 3 option buttons: light card background, option letter in gold circle, text in clear font.
- No time limit on normal events. (Heat-critical events show a countdown timer in red.)

## Dialogue Window

For story dialogue (non-choice, cutscene-style moments). Appears at the bottom of the screen.

```
┌─────────────────────────────────────────┐
│ RETTA  [portrait]                       │
│  "Well, Earl. I think this is going     │
│   to work out just fine."               │
│                              [Next ▶]  │
└─────────────────────────────────────────┘
```

- Speaker portrait on the left.
- Text readable in 2–3 lines.
- [Next ▶] or [Skip >>] to advance.
- Swipe left also advances.

## Ability Bar

Fixed row above the bottom navigation bar, visible only after Retta unlocks her first ability.

```
┌─────────────────────────────────────────┐
│  [🫖 Sweet Tea] [👁️ Stare] [📁 Coupon] [🧹 Sweep] │
│       Ready       12s       Ready        5s      │
└─────────────────────────────────────────┘
```

- 4 ability slots (configurable from the ability screen — swipe to see all 9).
- Each slot: 32×32 icon + label (2–3 word name) + cooldown timer.
- Ready state: icon fully colored.
- Cooling down: icon grayscale with a circular timer overlay.
- Tapping a ready ability: instant activation + quick animation on Retta's sprite.
- Long-pressing an ability: opens the ability detail screen (description, levels, upgrade).

## Heat Warning Banner

Appears at the top of the screen when Heat crosses 50, 75, or 100:

- **Heat 50:** Yellow banner, brief flash: *"People are talking."*
- **Heat 75:** Orange banner, pulse: *"Clem is watching."*
- **Heat 100:** Red banner + full-screen edge flash + audio sting: *"COMMUNITY CHECK-IN!"*

Banner is dismissable by tap after 3 seconds. Auto-dismisses after 6 seconds.

## Fonts

| Use | Style |
|---|---|
| Primary game UI | Bold, rounded sans-serif (evokes warmth and readability) |
| Dialogue text | Medium weight, slightly condensed (readable in small space) |
| Chapter titles | Slab-serif display font (Western-ish, charming) |
| Money/numbers | Monospace or tabular variant of primary font |
