# Section 13: Dialogue Decision Events (40 Events)

All events follow this format:
- **Situation** + NPC + NPC dialogue line
- "What do you do now?" prompt
- Option A / B / C with outcomes
- Effects: 💰 Money | 🌡️ Heat | ⭐ Reputation | 🃏 Backroom Status

Effects notation: +/– = change amount, 0 = no change.
